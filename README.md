# 🤖 Ardenne Robotics – Club Projects

Welcome to the official Ardenne Robotics collaborative project repository!

Students can contribute code, improve existing projects, fix bugs, and share their ideas.

## How to Contribute

**1. Fork this repository**
- Click the Fork button at the top-right.
- Select Create fork.

**2. Add your code**
- Open your forked repository.
- Upload your files or edit existing code.
- Make sure your changes work.

**3. Naming Your File**
- Use the format ProjectName-YourName.
- Keep the original file extension (e.g. .py, .js, .cpp).
- Place multiple project files in a folder with the same naming format.

**4. Submit your contribution**
- Click Contribute → Open pull request.
- Explain what you added or changed.
- Submit your pull request.

**5. Wait for review**
- The club maintainers will review your submission.
- Approved contributions will be merged into the main repository.

## Contribution Rules
- Keep your code organized.
- Give files clear names.
- Explain what your code does.
- Do not upload passwords or private information.
- Be respectful of other contributors.

**Happy building!**
